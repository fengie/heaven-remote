## Research decision before implementation

1. Preserve Sunshine/Moonlight and current pairing as the initial path. For desk use, spacedesk's documented direct-iOS-USB mode supports a separate Windows display. USB display transport is not proof of an IP path usable by Moonlight.
2. Use native Moonlight over a verified Ethernet LAN for a wired gaming baseline. A host adapter being Up does not establish the client's route. Confirm client radios are disabled and the stream remains active; then inspect Moonlight statistics. No automatic exit-node, UPnP, firewall or routing changes.
3. Keep Toolbox bound to loopback and display its Windows browser window on the extended screen. Do not expose the privileged controller on 0.0.0.0 to make Safari work. No copied private controller implementation.
4. Evaluate Apollo/SudoVDA as a later backend, not an automatic migration. Upstream recommends removing competing virtual-display solutions; per-client virtual-display identity is not independent Windows input/session isolation. Existing configuration/driver backup, rollback and native acceptance are prerequisites. Do not stack drivers or silently stream the wrong physical screen.
5. Prefer an inspectable native companion with separately testable policy logic over another troubleshooting ZIP, an unsolicited installer, a second web control daemon or a from-scratch streaming server. Port selected safe PhoneSeat logic with byte provenance; quarantine old hardware-mutation paths until reviewed. Keep the physical display active. Default remote geometry is 1920x1200; refresh selection is independent. 1080p is an explicit diagnostic alternative, not a silent replacement of the user's preference.
6. Use .NET 10 LTS for new native code; upstream lists .NET 8/9 end of support in November 2026. Avoid third-party runtime packages for the initial slice. The current container lacks dotnet/PowerShell and external DNS access; source/Node gates can run here, native compilation must be separately proven in Windows CI. This limitation does not certify old archives as buildable.
